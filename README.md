# 30-MONGODB-INTEGRATION-N-CRUD-APP

A full-stack CRUD (Create, Read, Update, Delete) application built using React, Node.js, Express.js, and MongoDB.

 **project demonstrates**

MongoDB database integration
Full CRUD operations
REST API development
Data validation
Error handling
Responsive frontend UI
Frontend-backend integration


**Features**

Create new records
Read all records
Update existing records
Delete records
MongoDB database connection
Form validation
API error handling
Responsive user interface
RESTful API architecture

**Technologies Used**

**Frontend**
React
CSS3
Fetch API
Responsive Design

**Backend**

Node.js
Express.js

**MongoDB**

Mongoose
dotenv
CORS
